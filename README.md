# EE Traceability Agent

A starter project for the EE Traceability Agent. This repository provides a minimal scaffold for parsing technical documents, exporting requirements, storing semantic vectors, and modeling traceability relationships.

## Repository Structure

- `data/`
  - `sample_specs.pdf` — sample technical PDF document
  - `input_requirements.xlsx` — placeholder Excel requirements file
  - `output/` — auto-generated output files
- `src/`
  - `__init__.py` — package initializer
  - `config.py` — configuration and directory helpers
  - `document_parser.py` — document parsing utilities
  - `excel_exporter.py` — Excel export helper
  - `vector_store.py` — vector store stub for semantic retrieval
  - `graph_agent.py` — graph modeling stub for traceability
  - `api.py` — FastAPI application and endpoints
- `app.py` — application entry point
- `requirements.txt` — Python dependencies

## Getting Started

1. Create a Python virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the API locally:

   ```bash
   python app.py
   ```

4. Open `http://localhost:8000` to validate the service.

## Notes

- `data/output/` is intended for autogenerated exports or reports.
- The source modules are currently stubs and can be extended with real parsing, export, and graph logic.
- Replace the placeholder `sample_specs.pdf` and `input_requirements.xlsx` with real artifacts for development.
